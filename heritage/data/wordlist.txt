# Kuzhi child-facing vocabulary list — the "500-word list" named (CRITIC-R2 #13).
#
# BASE = Dolch Sight Word List (220 service + 95 nouns = 315) UNION Fry Instant Words first 300.
# Both public domain, both named. Deduped at load time. Source: https://en.wikipedia.org/wiki/Dolch_word_list
# This is the standard early-reading vocabulary a Year 2-3 child is expected to read on sight.
#
# "Out-of-list" for a buddy hint = any word not in BASE and not in DOMAIN. DOMAIN words are the
# game's own nouns/verbs a child learns from the screen in the first minute; they are reported
# SEPARATELY so the Dolch-only figure is never inflated by them. Numbers and number words are
# never allowed in a hint at all (the lexical gate) so they are not listed here.
#
# Lines starting with # are comments. One word per line. Lowercase. "don't" keeps its apostrophe.
